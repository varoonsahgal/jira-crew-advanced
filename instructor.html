Rehearsal

Room-watching JQL

Keep these open in tabs during labs.

project = CRP AND updated >= -15m ORDER BY updated DESC
project = CRW AND updated >= -1h ORDER BY updated DESC
project = CRP AND labels is EMPTY AND created >= -1d
project = CRP AND labels = lab-07 ORDER BY updated DESC
If CRW changesFind the item and the user in its History, revert the field by hand, and tell the room which rule was broken without naming anyone. Re-check the answer-key queries for that item before the next demo.

Reset between cohorts

Non-destructive: nothing is deleted from CRP, so a learner's evidence links keep working.

  1. Relabel each used seat's items from lab-NN to archived-lab-NN (bulk edit with project = CRP AND labels = lab-NN).
  2. Recreate the seat's items from the manifest pattern (offsets 0–15, summary prefix LNN · , label lab-NN, the mislabeled offset 14 as lab-NN-swaps). New keys follow the last key in CRP, so update the seat table formula if you recreate rather than reuse.
  3. Delete every Lab NN scenario in the plan. Confirm Baseline shows no unsaved changes and the DEMO scenario is back to its starting state.
  4. Remove any comments learners added to seat epics if you want a clean epic, or leave them as history.
  5. Run the rehearsal answer-key queries again.
